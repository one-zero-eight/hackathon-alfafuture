# Стоимость и объём вызовов агентов

Раздел: agents
Дата: 2026-10-24 · Версия кода: рефакторинг на семь разделов (до первого коммита) · Автор: ИИ-агент по заданию

## Что измеряем
Сколько токенов и условных единиц стоимости (`usage.cost` шлюза; единица, по-видимому, рубль, это не подтверждено) уходит на один вызов каждого агента, чтобы оценить расход бюджета 500 ₽ в сутки.

## Метрика
Токены (`total_tokens`) и стоимость за один вызов, из счётчика `GET /usage`. Меньше лучше.

## Данные и окружение
Живой шлюз организаторов, модели по умолчанию из `registry.py`. Вход: «Делимобиль» / «Глава найма», один вызов каждого агента.

## Сравниваемые методы
Сравниваются сами агенты.

## Результаты
| Агент | Модель | Токены | Стоимость |
|---|---|---|---|
| `queries` | DeepSeek-V4.1-Flash | 16 713 | 1,02 |
| `needs` | DeepSeek-V4.1-Flash | 4 489 | 0,30 |
| `hyde` | DeepSeek-V4.1-Flash | 4 619 | 0,31 |
| `pick` (5 кандидатов) | GLM-5.3-Flash | 871 | 0,04 |
| `analytics_step` | DeepSeek-V4.1-Flash | около 1 650 | около 0,10 |

## Вывод
Самый дорогой разовый вызов — `queries` (рассуждения модели при лимите 32 000 токенов); результат кэшируется на сутки вместе с поиском. На профиль основную часть расхода даёт аналитика (десятки вызовов `analytics_step`), см. [analytics/benchmarks](../../analytics/benchmarks/page-cost.md).

## Ограничения
Один вызов на агента, без повторов; стоимость зависит от длины рассуждений модели. `decision`, `verify`, `reply`, `alfa_page` отдельно не замерялись.

## Как воспроизвести
```bash
curl -s -X POST localhost:8001/agents/hyde -H 'Content-Type: application/json' -d '{"input":{"company":"Делимобиль","line":"Глава найма"}}'
curl -s localhost:8001/usage
```
