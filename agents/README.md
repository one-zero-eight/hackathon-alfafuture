# agents — вызовы LLM

Единственное место, где Python-код обращается к LLM организаторов. Подробно: [docs/agents.md](../docs/agents.md).

Исключение: агент тегирования новостей (теги и геотеги) вызывается отдельно, внутри Go-сервиса `collector/` (пакет `llm/`), и в этот сервис не входит.

| Файл | Что внутри |
|---|---|
| `app.py` | всё остальное: клиент шлюза LLM (поток, резервный шлюз, список разрешённых моделей), одиннадцать агентов, учёт расхода, HTTP: `POST /agents/{имя}`, `GET /agents`, `GET /usage`, `GET /health` |
| `tracing.py` | строгие события, контекст запуска, HTTP-доставка в backend и безопасный резервный лог |
| `feedback.py` | строгая схема feedback_intent и проверка допустимых целей/URL/дословного текста |
| `client.py` | клиент для других сервисов (копируется в их образы) |
| `prompts/` | шаблоны запросов, `{поле}` подставляется из входа |
| `benchmarks/` | отчёты о стоимости и качестве |

```bash
uv sync --all-packages
uv run pytest agents                                   # офлайн
uv run uvicorn agents.app:app --port 8001              # нужны LLM_API_KEY и LLM_BASE_URL в окружении
```

Новый агент — это новый шаблон в `prompts/` и запись в `AGENTS` в `app.py`, существующие не переписываются.

`trace_description` — Gemma выбирает допустимое оформление фактов журнала; backend вставляет реальные значения и кэширует результат. По умолчанию выключен: `TRACE_AI_ENABLED=false`. `TRACE_BACKEND_URL` включает доставку событий в backend; клиент передаёт контекст автоматически. События содержат метрики и безопасные коды, без промптов/ответов. Детали неизвестного usage и сетевых повторов — в docs/agents.md.

`feedback_intent` (#26) — Gemma распознаёт семь сценариев и clarify, не исполняет команд и не генерирует изменения страницы. Проверка набора (80 примеров, бесплатно): `uv run python -m agents.benchmarks.feedback_intents`. Живой замер требует явного `--live --max-cost <лимит>` и заранее согласованного бюджета; фикстуры не подтверждают macro-F1. Описание — docs/agents.md и benchmarks/feedback-intents.md.
