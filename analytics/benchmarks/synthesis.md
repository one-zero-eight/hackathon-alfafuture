# Синтез нескольких новостей в один вывод

Раздел: analytics
Дата: 2026-10-26 · Версия кода: ветка `analytics/synthesis-bank`, база c3d42c1 · Автор: Лев

## Что измеряем
Даёт ли отдельный шаг один вывод по нескольким новостям для сферы, а действие — уже для компании. Гипотеза: в запрос вывода не попадают название и выручка, в запрос действия попадают, цитаты остаются дословными, горизонт не зашит как «среднесрочно».

## Метрика
- Доля страниц, где есть виджет `s1` минимум с двумя дословными цитатами из разных новостей. Больше — лучше.
- Совпадение текста сферы для двух компаний одного ОКВЭД и региона. Должно совпадать.
- Доля действий `sd1`, у которых горизонт не `medium_term`, на страницах, где модель выбрала другой срок.
- Токены и cost шлюза на одну страницу. Меньше — дешевле.

Живой судья на 20–30 парах «компания × новость» не запускался: одна страница и так тратит десятки вызовов, а дневной бюджет 500 ₽.

## Данные и окружение
Офлайн-тест `analytics/test_chain.py`: две новости, подменённые агенты, профиль добычи в Тверской области и тот же профиль с другим названием и другой выручкой. Модели организаторов в этом прогоне не вызывались.

## Сравниваемые методы
| Метод | Чем отличается | Параметры |
|---|---|---|
| цепочка по одной новости | как раньше, виджеты `a` и `d` | без изменений |
| синтез | агенты `synthesis` и `synthesis_decision`, виджеты `s1` и `sd1` | сфера без частных фактов, факты только в действии |

## Результаты
Проверка подменёнными агентами, 2026-10-26:

| Проверка | Результат |
|---|---|
| две новости дают один `s1` и один `sd1` | да, плюс прежние цепочки |
| текст сферы одинаков для двух компаний одного ОКВЭД и региона | да |
| название и выручка отсутствуют в запросе `synthesis` | да |
| выручка есть в запросе `synthesis_decision` | да |
| горизонт `sd1` в фикстуре | `not_urgent`, не константа |
| токены живого прогона | не измерялись |

## Вывод
Шаг добавлен отдельным модулем. Вывод по одной новости тоже пишется про сферу: название и выручка в его запрос не входят, они есть только у решения. Срок решения берётся из ответа модели. Живое сравнение «до и после» на 20–30 компаниях не делалось.

## Ограничения
Судья-LLM не смотрел, полезнее ли синтезированный вывод пересказа одной новости. Горизонт в тесте задан ответом подмены, не моделью.
