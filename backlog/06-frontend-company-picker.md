# Интерфейс: выбор компании одной кнопкой

Разделы: `frontend`, `backend`.

При входе в интерфейс можно одной кнопкой выбрать одну из компаний из `external-docs/company/`.

## Задача

1. Подготовить список демонстрационных компаний. В CSV около 85 тыс. записей, показать все нельзя. Предложение: 8 компаний, стратифицированных по ОКВЭД, региону, размеру, в фиксированном файле. Нужно решение пользователя.
2. Бэкенд: новый маршрут со списком этих компаний; контракт в `docs/backend.md`. Бэкенд уже собирает карточку по id вида `U_123`.
3. Фронтенд: на экране входа кнопки компаний; клик запускает тот же поток, что ввод `U_123`.
4. Проверка: браузер на десктопе и мобильной ширине, консоль без ошибок, curl для маршрута, тесты.
