# Тест полного прогона и сборки системы

Раздел: `docker`.

Замерить полный прогон и сборку всей системы:
- время сборки образов (с кэшем и без) и их размер;
- время старта стека до готовности;
- время прогона по шагам (профиль, поиск, дедупликация, аналитика, решения);
- расход токенов по каждому из девяти агентов и в рублях против лимита 500 ₽/день;
- сужение воронки: сколько новостей остаётся на каждом шаге;
- расход памяти по контейнерам (`docker stats`);
- то же для каждого метода поиска (lexical, dense_llm, dense_xquad).

## Задача

1. Скрипт замера `docker/benchmark.sh`.
2. Прогон для 3–5 компаний из задачи 06 по каждому методу поиска. Сначала оценить стоимость, потом запускать: прогон тратит реальный бюджет.
3. Отчёт `docker/benchmarks/full-run.md` по шаблону, с указанием железа; список узких мест и план оптимизаций.

Лучше запускать после задач 01–03 и 06.
