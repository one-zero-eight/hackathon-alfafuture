# Сборщик: обновить список тегов

Разделы: `collector`, `docs`.

Сейчас многие политические новости получают только один тег — «РФ». Нужно это исправить и дополнить словарь (сейчас 525 тегов: geography 365, industry 112, event 36, resource 8, economic_group 4).

## Задача

1. Измерить проблему: разметить выборку примерно из 300 политических новостей текущим словарём, посчитать долю новостей с единственным тегом «РФ». (В текущей БД тегов нет, измерить на ней нельзя.)
2. Найти непокрытые политические темы: санкции, внешняя политика, налоговая и бюджетная политика, законодательство, безопасность, выборы и госуправление, международные организации.
3. Дополнить словарь (новая версия, старая не ломается). Теги только из фиксированного словаря, модель их не придумывает. Нужно решение пользователя: новое измерение или новые ветки в существующих.
4. Повторить замер на той же выборке и сравнить.
5. Обновить `docs/collector-tag-vocabulary.md`.

## Готово, когда

Доля политических новостей с единственным тегом «РФ» заметно упала (цель согласуется после первого замера); тесты `collector` зелёные.
