# Аналитика: ТРИЗ в разборе новостей

Раздел: `analytics`.

Выяснить, как часто ИИ находит неочевидные аналитические решения при использовании методов ТРИЗ и как эффективно он использует аналитику Альфа-Банка.

## Задача

1. Собрать 20–30 пар «компания × новость» из разных отраслей.
2. Для каждой пары прогнать цепочку дважды: с ТРИЗ и без (шаг должен отключаться флагом).
3. Оценить неочевидность решений по рубрике: судья-LLM (другая разрешённая модель) плюс ручная проверка 20 решений командой; записать согласие судьи с людьми.
4. Для ссылок на аналитику банка проверить: тезис дословно есть в PDF, относится к выводу, добавил содержание, а не украсил.
5. Посчитать: долю неочевидных решений с ТРИЗ и без, прирост, долю решений с проверенной ссылкой на тезис банка, токены на решение.
6. Отчёт `analytics/benchmarks/triz-and-bank-research.md` по шаблону `docs/benchmark-template.md`; вывод: оставлять ли ТРИЗ по умолчанию и что менять в промптах.

Не измеряется: реальная польза решений для бизнеса.
