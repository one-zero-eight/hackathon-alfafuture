# Memo U14: CEO, IT services (OKVED J), Moscow, small company, salary bank product

## 1. Decisions now

1. **Patch PHP across our stack and confirm which sites are exposed.** Owner: CTO. Items: A1507, A1495, A1730. Path: two critical PHP vulnerabilities were disclosed on 20 October, and sites in several European countries were taken offline as a precaution. An AI model found one of the bugs. Check: applies only if we run PHP. Confirm and apply the fixes the PHP project released.

2. **Check whether any client or hosting provider depends on a single data-centre region.** Owner: CTO. Items: A0025. Path: reports say attacks on Yandex data centres in Ryazan disrupted court systems and caused hearing postponements. Check: applies if we host on the same provider or depend on it for client work. Confirm our failover.

3. **Review our backup and fallback for telecom and hosting outages, in line with the Mintsifry plan.** Owner: CTO. Items: A1527, A0884. Path: the ministry has set up a task force and reserved critical nodes and backbone lines against drone attack. Check: this is for telecom operators, but it signals risk to network suppliers. Confirm which providers are on the critical list.

4. **Confirm whether we need a telecom licence if the reform goes ahead.** Owner: legal. Items: A1633. Path: the ministry is preparing licensing reform, including capital and coverage requirements for operators. Check: applies only if we provide telecom services. No action unless we do.
