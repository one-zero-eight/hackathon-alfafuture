# Журнал запусков: накладные расходы и проверка HTTP

Раздел: backend
Дата: 2026-10-26 · Версия: backend/run-journal (рабочее дерево)

## Что измеряем

Гипотеза: строгие события почти не меняют время локального поиска; основная цена — запись в PostgreSQL. Отдельно проверяем полный журнал через реальные HTTP/curl для трёх методов. Живую Gemma и её стоимость сейчас не измеряем: валюта шлюза и доступный дневной бюджет не подтверждены.

## Метрика

Медиана и min–max времени поиска, мс (меньше лучше), число записанных событий. Для HTTP — число публичных событий, число фикстурных LLM-вызовов, итоговый статус и признак неполноты. Для будущего замера Gemma: сумма известных `gateway.usage.cost` и токенов по вызовам `trace_description` на запуск; неизвестный расход отдельно, без объявления единиц рублями. Вложенные события `llm` повторно не суммируются.

## Данные и окружение

Docker Desktop Linux: 20 CPU, около 61,2 GiB RAM по Docker API. Python 3.13, uv workspace, PostgreSQL 18.6 в отдельном контейнере и временной схеме. Фикстура `make_corpus`: 120 синтетических статей, `hash_encoder` вместо нейросетевого энкодера, `PYTHONHASHSEED=0`. Пять холодных прогонов на вариант, без кэша результата. Модели и LLM заменены фикстурами; реальные платные запросы не отправлялись.

## Сравниваемые методы

- `off`: контекста нет, вызовы событий ничего не сохраняют.
- `memory`: схема/контекст и накопление событий в памяти.
- `postgres`: каждая запись через backend-owned хранилище с отдельным подключением; создание запуска вне измеряемого интервала.

## Вывод

Локальная проверка схемы мала относительно фикстурного поиска; запись через отдельные подключения добавляет около 67–99 мс на этот небольшой поиск. Сохраняем простой синхронный механизм. При недоступности доставки дальнейшие события запроса уходят в безопасный резервный лог, запрос помечается неполным. Генерация Gemma остаётся по запросу и выключена до подтверждения валюты/бюджета.

## Ограничения

Не измерены промышленный корпус, настоящие эмбеддеры, задержки продакшен-сети, долговременная нагрузка и реальная Gemma. Результаты фикстур не оценивают качество новостей или модели. Числа поиска не включают LLM-телеметрию: в микробенчмарке агенты заменены локальными объектами. Полный curl-smoke включает HTTP-доставку и LLM-события, но не является замером задержки. Стоимость в рублях и соблюдение общего лимита 500 ₽/сутки не подтверждены.

## Как воспроизвести

Предпосылки: uv workspace и отдельная PostgreSQL; обе команды создают и удаляют только собственную временную схему.

```bash
uv sync --all-packages
TEST_DATABASE_URL='postgres://news_test:news_test@127.0.0.1:<port>/news_test?sslmode=disable' PYTHONHASHSEED=0 uv run python -m backend.benchmarks.journal_bench
TEST_DATABASE_URL='postgres://news_test:news_test@127.0.0.1:<port>/news_test?sslmode=disable' PYTHONHASHSEED=0 uv run python -m backend.benchmarks.journal_smoke
```
