# Скорость сборки карточки компании из данных банка

Раздел: backend
Дата: 2026-10-24 · Версия кода: рефакторинг на семь разделов (до первого коммита) · Автор: ИИ-агент по заданию

## Что измеряем
Сколько занимает `CompanyBook.profile(uid)` на полных файлах организаторов.

## Метрика
Секунды на первую карточку (включает загрузку таблицы компаний и один проход по платежам). Меньше лучше.

## Данные и окружение
`df_Uid_data_hack.csv` (85 525 компаний, 31 МБ) и `df_Uid_payment_hack.csv` (1 380 585 платежей, 39 МБ), ноутбук разработчика, Python 3.13.

## Сравниваемые методы
Один вариант: таблица компаний грузится один раз, платежи читаются потоком для одной компании без загрузки в память.

## Результаты
| Операция | Время |
|---|---|
| Первая карточка (U_76) | 1,3 с |

## Вывод
Достаточно для очереди профилей; индекс платежей не нужен, пока файл не вырастет на порядок. Если вырастет, платежи стоит загрузить в Postgres.

## Ограничения
Одна компания, один замер, холодный диск не исключён.

## Как воспроизвести
```bash
uv run python -c "from backend.companies import CompanyBook; print(CompanyBook('external-docs/company').profile('U_76')['description'][:200])"
```
