# Допоиск `refine`

Раздел: news_search
Дата: 2026-10-25 · Версия кода: ветка `news_search/refine` (до первого коммита) · Автор: ИИ-агент по заданию

## Что измеряем
Работает ли допоиск (#27) на реальном корпусе для каждого вида: не возвращает уже показанное и его дубли, уводит выдачу от удалённых новостей, сколько стоит и сколько длится. Гипотеза: без новых вызовов LLM допоиск по вектору текста быстрый и бесплатный, а исключения и штраф полностью убирают показанное и похожее на удалённое.

## Метрика
- **Дубли показанного** (шт. из 10, меньше лучше): результаты, которые `dd_hybrid` склеивает с любой показанной новостью; **в показанном** — совпадение по `aid`.
- **Близко к удалённым** (до → после, меньше лучше): сколько результатов имеют косинус ≥ 0,7 с удалённой новостью. «До» — оставшиеся 7 новостей первого прогона темы, из которого удалены 3; «после» — 10 новостей повторного прогона с этими 3 в `removed_aids`.
- **Пересечение «тема» и «перспектива»** (из 10, меньше лучше): одинаковые новости при той же теме и другом регионе.
- Задержка (с), стоимость (`usage.cost` шлюза; единица, по-видимому, рубль).
- Релевантность выдачи не оценивалась: способ оценки (судья или ручная разметка) не выбран.

## Данные и окружение
Корпус из дампа `news_corpus.dump`: 122 760 статей, 119 251 за 365 дней. Векторы bge-m3 из кэша (104 тыс.) + досчитано около 15 тыс. на CPU. Docker на Apple M4 (CPU), `news_search` в контейнере. Модели: DeepSeek-V4.1-Flash через `agents` (`queries`, `needs`, `hyde`).

6 профилей, входы утверждены пользователем:

На профиль: `/search` (его 30 новостей — «показанные»), затем `refine` с `limit=10`: тема; та же тема с другим регионом; вывод; ссылка (30-я новость допоиска по теме с `limit=30`, заголовок + аннотация; её `aid` тоже в исключениях); повтор темы с 3 первыми результатами в `removed_aids` и остальными 7 в исключениях.

## Сравниваемые методы
Один метод — `refine` поверх `dense_xquad`, параметры: `REMOVED_SIM = 0,7`, `REMOVED_FACTOR = 0,5`, 150 кандидатов.

Наблюдения по выдаче (просмотр глазами, не разметка):
- Тема и вывод в целом попадают в смысл (курьеры и зарплаты; экспорт рыбы в Китай; тарифы и контейнеры РЖД), но бывают ложные совпадения по слову («Инвестиции в микроэлектронику» на «микромобильность»; возврат билетов РЖД на «тарифы РЖД»).
- **Перспектива не работает**: другой регион меняет только блоки запросов для xQuAD, а кандидаты отбираются по вектору одной темы — выдача совпала 10 из 10 во всех профилях, при этом за неё платится вызов `queries`.
- **Пересказы одной новости не склеиваются**: «Беспилотные грузовики между Казахстаном и Китаем» — 3–4 раза в одной десятке (U_76, Инарктика). `dd_hybrid` ловит одинаковые ссылки и близкие заголовки, но не пересказы.
- Ссылка: выдача вокруг вставленной новости, но в неё попадают соседние региональные новости того же издания (НГС24 для Делимобиля).

## Вывод
- Исключение показанного и удалённого работает: 0 дублей и 0 совпадений во всех 30 прогонах; после удаления похожих на удалённое новостей в выдаче нет (до 6 из 7 у U_76).
- Допоиск по теме, выводу и ссылке быстрый (около 5 с) и бесплатный.
- Перспективу и склейку пересказов нужно исправить; изменения алгоритма — после обсуждения с пользователем.

Вывод прогона 2: склейка пересказов работает; перспектива перестала стоить денег и времени, но регион почти не учитывается — нужен другой способ (повышение новостей региональных изданий или HyDE под регион), это решение пользователя.

## Ограничения
- Релевантность не размечена; качество описано по просмотру, без чисел.
- «После» для удалённых считается тем же порогом 0,7, что и штраф, поэтому 0/10 частично следует из устройства метрики; влияние штрафа отдельно от исключения не измерено.
- Один прогон, 6 профилей, по одному тексту на вид; ссылка выбрана автоматически из выдачи по теме.
- 94 % статей корпуса — только заголовок (#16), векторы считаются по заголовку и 300 знакам.
- Векторы считались на CPU в Docker; задержка на GPU будет другой.

## Как воспроизвести
```bash
docker compose --env-file .env -f docker/compose.yaml up -d postgres agents news_search
docker compose --env-file .env -f docker/compose.yaml cp news_search/benchmarks/refine_bench.py news_search:/tmp/refine_bench.py
docker compose --env-file .env -f docker/compose.yaml exec -T -e PYTHONPATH=/app news_search python /tmp/refine_bench.py > refine_runs.json
curl -s localhost:8001/usage
```
Корпус: `pg_restore` дампа в `postgres` из compose; без кэша векторов первый запуск считает векторы всего корпуса.
