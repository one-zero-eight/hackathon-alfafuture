# Параметры компании и уровень новостей

Раздел: news_search
Дата: 2026-10-26 · Версия кода: ветка `analytics/synthesis-bank`, база c3d42c1 · Автор: Лев

## Что измеряем
Какое поле компании меняет новости в выдаче и их уровень: свой регион, чужой регион, федеральные, зарубежные. A/B здесь офлайн: живых пользователей нет, для одной и той же компании сравниваются два профиля на одном и том же срезе новостей. Полный профиль — сторона A, тот же профиль без одного поля — сторона B.

Гипотеза: регион и отрасль двигают уровень новости, размер компании нет. Капитализации в файлах нет, размер — это `REVENUE_COMPANY`.

## Метрика
- Пересечение топ-10: доля новостей полного профиля, которые остались в топ-10 без поля. 1 значит, что поле выдачу не меняет. Меньше значит, что поле меняет набор.
- Корреляция порядка: Спирмен мест топ-10 полного профиля в списке без поля. Новость, выпавшая из топ-10, получает место сразу за десятым. 1 значит, что порядок тот же.
- Разнообразие: сколько разных уровней среди четырёх (свой регион, чужой, федеральные, зарубежные) попало в топ-10, делённое на 4.
- Доля федеральных и доля своего региона внутри топ-10.
- Релевантность: судья `qwen/qwen3.6-35b-a3b` выбирает, какой список полезнее компании. A — полный профиль лучше, B — без поля лучше, same — одинаково. Судья вызывается только для полей, у которых пересечение ниже 0,85: если список почти тот же, релевантность та же. По 8 компаний на такое поле.
- Токены поиска на профиль: 0. Запросы модели не писались. Токены судьи считаются отдельно.

Лучше для отбора: поле, которое меняет список и при этом судья чаще выбирает полный профиль. Поле, которое меняет список, а судья выбирает урезанный, — шум.

## Данные и окружение
85 525 компаний, `external-docs/company/df_Uid_data_hack.csv`. Филиал человека — `df_Fid_Uid_link_hack.csv` (город и РЦ, самое частое значение по компании). Платежи — `df_Uid_payment_hack.csv`, отрасль крупнейшего внешнего плательщика. 2 008 сюжетов недели с регионом и ОКВЭД, файл `exp/v2/p1/cards.jsonl` ветки `ranking/reasoning-chain`.

Выборка: 48 компаний, по очереди из разных макрорегионов, классов ОКВЭД и полос выручки (от 15 млрд, 1–15 млрд, меньше 1 млрд). Численность СПАРК есть у 168 компаний, факторинг у 213, поэтому 8 мест в выборке отданы компаниям с этими полями, иначе у них было бы ноль наблюдений. Неразмеченных регионов нет.

Задача #16 ещё открыта, базы новостей коллектора отсюда нет (Postgres на 5432 просит пароль, в `.env` его нет). Метод бэкенда по умолчанию — `dense_xquad`. Этот прогон его не вызывает: на 48 компаний и 19 полей это сотни запросов модели. Поиск здесь — пересечение основ слов профиля и заголовка, то есть поиск по заголовкам, который задача прямо разрешает, пока #16 не закрыта. Подмена значения поля не делалась, поле убиралось целиком.

## Результаты
Топ-10 полного профиля, среднее по 48 компаниям: разнообразие 0,78. Свой регион 4,6%, федеральные 30%. У 115 компаний с выручкой от 15 млрд полка «новости той же отрасли» другая: свой регион 5,8%, чужой 20,3%, федеральные 48,8%, зарубежные 25,1%. Слова профиля не собирают региональную полку. Из 53 сибирских сюжетов недели Иркутск назван в одном.

Пример. Больница в Новосибирске, `U_189987`. Слово «область» из региона притянуло «Ровенскую область» и «Херсонскую область». Слова «выручка» и «млрд» притянули новости о выручке чужих компаний. После удаления региона или выручки эти заголовки из топ-10 выпали. Название ОКВЭД «больничных организаций» топ-10 не сдвинуло.

## План действий
Код поиска этим прогоном не менялся. Ниже — что усиливать и что убрать из текста запроса. Сейчас бэкенд кладёт в запрос ОКВЭД, город, регион, численность, возраст, внешнюю торговлю и отрасли поставщиков и покупателей. Выручка, продукты и группа живут только в фактах для вывода.

| Параметр | Что делать |
|---|---|
| ОКВЭД | Оставить признаком отрасли, отбирать по разделу ОКВЭД на карточке новости. Слова названия ОКВЭД в мешок запроса не усиливать: судья ни разу не предпочёл полный список, в 4 случаях из 8 лучше был список без ОКВЭД. Без этого поля федеральных в топ-10 больше (0,30 → 0,36), свой регион не меняется. |
| Регион | Отбирать по метке географии сюжета и держать отдельные места для своего макрорегиона, федеральных и зарубежных. Общие слова «область», «край», «республика» в запрос не класть: они цепляют чужие регионы, а доля своего региона с полем и без него одна, около 5%. |
| Город | В запрос отдельно не добавлять. При оставленном регионе топ-10 тот же. |
| Выручка | Убрать из запроса, оставить в фактах для вывода. Это самое сильное смещение списка (пересечение 0,62), и оно идёт за словами «выручка» и «млрд», а не за уровнем новости: федеральные 0,30 → 0,32. Судья в 5 случаях из 8 предпочёл список без выручки, в одном — полный. |
| Численность ФНС | В запрос не класть. Сдвиг небольшой, уровень не меняется. В фактах можно оставить. |
| Возраст, тип организации, тип клиента, негативная отметка, численность СПАРК, факторинг | Убрать из запроса. Топ-10 не меняется. Тип организации у всех 85 525 компаний один: КОММ_ОРГ. СПАРК и факторинг почти ни у кого не заполнены. |
| Форма собственности, эко-метка, группа, продукты банка, внешняя торговля, платежи, город и РЦ филиала | В запрос не усиливать. Сдвиг слабый, полка своего региона не появляется. Продукты, платежи и внешнюю торговлю оставить в фактах для вывода, где они уже есть. |

Дальше, отдельным изменением, не в этом замере: повторить то же A/B методом `dense_xquad` на корпусе коллектора, когда закроется #16. До этого цифры выше — про заголовки.

## Вывод
Размер компании не выбирает федеральные новости против региональных. Выручка сильнее всех двигает список и делает это шумом. Регион и ОКВЭД тоже двигают список, но судья не считает полный профиль релевантнее, а свой регион в топ-10 от этих слов не растёт. Усиливать надо метку отрасли и метку географии на карточке новости. Из текста запроса убрать выручку, возраст, численность и служебные метки банка.

## Ограничения
Это не `dense_xquad` и не лексический поиск с запросами модели. Корпус — одна неделя, не лента коллектора. У центрального округа кроме Москвы нет своей метки в карточках, для Воронежа и соседних областей «свой регион» занижен. Судья смотрел 8 компаний и только три поля; продукты, платежи и численность ФНС он не размечал, потому что пересечение было 0,85 и выше. Подмена значения поля на другое не проверялась.

## Как воспроизвести
```bash
git show origin/ranking/reasoning-chain:exp/v2/p1/cards.jsonl > /tmp/week-cards.jsonl
PYTHONPATH=. uv run python news_search/benchmarks/personalization_ab.py /tmp/week-cards.jsonl
PYTHONPATH=. uv run python news_search/benchmarks/personalization_ab.py /tmp/week-cards.jsonl --judge 8
uv run python -m pytest news_search/test_levels.py -q
```
Ключ судьи берётся из `.env`. Повторный `--judge` не вызывает модель заново для уже записанных пар.
